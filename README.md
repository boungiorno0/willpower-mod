# Willpower Constructs (Fabric, Minecraft 1.21.1)

Оригинальный мод про кольцо воли, создающее временные светящиеся зелёные конструкты.

## Что в моде

**Кольцо воли** (`willpower:will_ring`)
- ПКМ — создать конструкт в текущем режиме.
- Shift + ПКМ — сменить режим.
- Режимы: Мост (3×16), Стена (5×4), Платформа (5×5), Щит (сфера радиусом 3), Рывок.
- У кольца есть заряд (в тултипе, в %). Каждый режим тратит свой запас, кольцо не ломается.
- Заряд медленно восстанавливается само, пока кольцо в инвентаре.

**Хранилище воли** (`willpower:will_reservoir`)
- ПКМ кольцом по блоку — мгновенная полная подзарядка.

**Конструкт воли** (`willpower:will_construct`)
- Полупрозрачный светящийся блок, исчезает через 15 секунд. Ломается мгновенно, ничего не роняет.

## Рецепты

- Кольцо: 4 золотых слитка + изумруд (крест).
- Хранилище: 4 стекла (углы) + 4 изумруда + светящийся камень в центре.

## Сборка

Нужны JDK 21 и Gradle.

1. В папке проекта выполни `gradle wrapper --gradle-version 8.10` (создаст `gradlew`).
2. `./gradlew build` — готовый мод появится в `build/libs/willpower-constructs-1.0.0.jar`.
3. Для запуска в игре из IDE: `./gradlew runClient`.

Версии Fabric Loader / Yarn / Fabric API лежат в `gradle.properties`. Если Gradle ругается на версию,
посмотри актуальные на https://fabricmc.net/develop и обнови их.

## Идеи для развития

- Кастомные звуки и анимация кольца.
- Конструкты других форм (лестница, купол, меч).
- Цвета колец и энергия, зависящая от опыта игрока.
